Furqan Labs - Landing Page

A premium, multi-section landing page designed and developed for Furqan Labs during my remote internship at Oasis Infobyte.

This project was built using pure HTML5 and CSS3, focusing on clean UI design, responsive layouts, and modern web development practices without the use of frameworks or JavaScript.

🚀 Features

- Modern hero section with strong typography and clear call-to-action buttons
- Services and capabilities showcase
- Professional pricing card layouts
- Client testimonials and endorsements section
- Fully responsive design optimized for different screen sizes
- Clean and maintainable HTML & CSS structure

🛠️ Tech Stack

- HTML5
- CSS3
  - Flexbox
  - CSS Grid
  - Media Queries

▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch "index.html" in any modern web browser.

## 📖 Overview

Thermex is a premium temperature converter that provides fast and accurate conversions between **Celsius**, **Fahrenheit**, and **Kelvin**.

It features a modern user interface, live conversion, conversion history, dark/light theme support, and a responsive design that works seamlessly across desktop and mobile devices.

This project was developed as **Task 3** for the **Oasis Infobyte Web Development Internship (OIBSIP)**.

---

## ✨ Features

- Instant temperature conversion
- Celsius, Fahrenheit, and Kelvin support
- Live conversion mode
- Swap units
- Absolute zero validation
- Input validation
- Conversion history using Local Storage
- Copy results to clipboard
- Dark & Light theme
- Responsive design
- Glassmorphism user interface
- Keyboard shortcuts

## 🎮 Usage

1. Enter a temperature value.
2. Select the input unit.
3. Click **Convert Temperature**.
4. View the converted values.
5. Enable **Live Mode** for instant conversion.
6. Use **Swap** to quickly change units.

---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl + Enter | Convert Temperature |
| Alt + U | Open Unit Selector |
| ↑ / ↓ | Navigate Units |
| Enter | Select Unit |
| Esc | Close Selector |

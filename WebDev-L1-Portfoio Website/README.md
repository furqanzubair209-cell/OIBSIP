## 📖 About

This portfolio serves as my digital résumé, highlighting my education, technical skills, projects, certifications, achievements, and experience. It is built using **HTML5, CSS3, and Vanilla JavaScript** with a modern dark UI and fully responsive design.

---

## ✨ Features

- 💻 Modern dark theme with glassmorphism UI
- 📱 Fully responsive & mobile-first
- ⚡ Built with pure HTML, CSS & JavaScript
- 🎬 Typing animation & terminal-style hero section
- 🎯 Smooth scrolling and active navigation
- 📊 Scroll progress indicator & Back-to-top button
- 🛠️ Skills, Experience, Projects & Education
- 📜 Certifications with search & filter
- 📬 Contact form and social media links
